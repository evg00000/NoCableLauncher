# Changelog

## 2.1

- Английский интерфейс. Язык выбирается автоматически по языку Windows (русский для ru/uk/be/kk,
  английский для остальных) или вручную: «Дополнительно» → «Язык / Language» (`[UI] Language=auto|ru|en`).
- Сообщения журнала тоже выводятся на выбранном языке.

## 2.0

Первый выпуск форка (на основе Maxx53/NoCableLauncher 1.0).

- Добавлен режим RS_ASIO: установка в папку игры, настройка `RS_ASIO.ini` и `Rocksmith.ini`, автоматическое
  удаление при переключении обратно в режим NoCable.
- На время игры автоматически скрываются остальные входы и выходы, а выбранные устройства становятся
  устройствами по умолчанию.
- Автоматическое переключение частоты и разрядности входа и выхода (по умолчанию 48000 Гц / 24 бит).
- Все изменения звука записываются в журнал и возвращаются после выхода из игры, в том числе после
  аварийного завершения (`-restore`).
- Исправлена ошибка «Offcets not found»: память читается по регионам, поиск повторяется с тайм-аутом,
  ошибка сопоставления шаблона исправлена, патч проверяется после записи, перезапуск игры Steam'ом отслеживается.
- Исправлена работа с адресами выше 2 ГБ в 32-битном процессе.
- Новое окно настроек на русском, настройки в `NoCableLauncher.ini`, журнал работы в `NoCableLauncher.log`.
- Сборка встроенным в Windows `csc.exe` (`build.bat`) и в GitHub Actions.
